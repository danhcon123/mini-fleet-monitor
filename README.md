# Mini Fleet Monitor

Full-stack application for monitoring robot fleet positions in real-time.

## Architecture

- **Backend**: Node.js + Express + TypeScript + PostgreSQL + WebSocket
- **Frontend**: React + TypeScript + Leaflet/MapLibre

## Quick Start
```bash
# Start all services
docker-compose up

# Backend: http://localhost:8080
# Frontend: http://localhost:5173
```

See `/backend/README.md` and `/frontend/README.md` for detailed documentation.
